Connect your organization

Azure DevOps Notifier watches pull requests on Azure DevOps Services (dev.azure.com) and notifies you about comments, reviews, checks and more. Azure DevOps Server (on-premises) is not supported.

Create a PAT at dev.azure.com/{org}/_usersSettings/tokens with scopes:

  • Code (Read): read pull requests, threads, statuses
  • Project and Team (Read): list projects for scope selection

The token is stored only in this extension's local Chrome storage (not synced, not encrypted by the OS keychain) and is never sent anywhere except dev.azure.com. Set an expiry on the PAT and revoke it when no longer needed.

Polling

Polling only runs while Chrome is open. Only changes observed between checks are reported, so activity between polls may be missed. Checks cover pull request statuses and policy evaluations, not every pipeline run.

Desktop alerts need Chrome's optional “notifications” permission. Your OS notification settings may also apply.
